# Демо: сайт ЖК с каталогом квартир на WordPress

Демонстрационный проект для портфолио. Тема написана с нуля, без конструкторов. Логика каталога вынесена в отдельный плагин, поэтому тему можно поменять, не потеряв данные.

**Открыть демо в браузере** (WordPress запускается прямо во вкладке, установка не нужна, первый запуск ~30–60 секунд):
https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/knaknaproduct/wp-zhk-catalog-demo/main/blueprint-online.json

Админка: `/wp-admin/`, вход выполняется автоматически.

## Что умеет

**Для посетителя**
- Каталог квартир с фильтрами: комнаты, цена, площадь, этаж, корпус, отделка, «только свободные». Есть сортировка и кнопка «Показать ещё». Фильтры применяются без перезагрузки страницы и сохраняются в адресе, поэтому подборкой можно поделиться ссылкой.
- Страница квартиры: планировка, параметры, цена и цена за м², похожие квартиры.
- Избранное без регистрации (хранится в браузере), счётчик в шапке.
- Окно заявки: маска телефона, согласие на обработку данных, привязка к квартире.
- Главная: первый экран, галерея с просмотром в полный размер, интерактивная карта инфраструктуры с фильтром по категориям, новости.
- Адаптивная вёрстка (проверена на ширине 375 px), доступность с клавиатуры, `prefers-reduced-motion`.

**Для менеджера (админка)**
- Квартиры: колонки с ценой и статусом, сортировка, фильтры по статусу и корпусу, быстрое изменение цены и статуса прямо в списке.
- Импорт и экспорт CSV: выгрузить, поправить в Excel, загрузить обратно. Квартира ищется по корпусу и номеру. Поддерживаются разделители `;` и `,` и кодировка Windows-1251. Отчёт показывает ошибки с номерами строк.
- Раздел «Заявки» и письмо на почту (адрес задаётся в Настройки → Общие).
- Метрика и GTM: номер счётчика или ID вводится в «Внешний вид → Настроить». Цели `lead_submit`, `favorite_add` и `favorite_remove` отправляются автоматически.

## Как устроено

```
plugin/zhk-catalog/              данные и логика
  includes/class-apartment.php   тип записи, схема полей, выборка и диапазоны фильтров
  includes/class-rest.php        GET /wp-json/zhk/v1/apartments, POST /wp-json/zhk/v1/leads
  includes/class-leads.php       заявки: проверка полей, honeypot, лимит частоты, письмо
  includes/class-admin.php       форма квартиры, колонки, быстрое редактирование
  includes/class-importer.php    импорт и экспорт CSV
  includes/demo.php              демо-данные
theme/zhk-theme/                 внешний вид
  assets/js/catalog.js           каталог, избранное, похожие квартиры (одна функция карточки)
  assets/js/app.js               избранное, окно заявки, меню, галерея
  assets/js/map.js               карта (Leaflet + OSM)
```

- Схема полей квартиры описана в одном месте (`ZHK_Apartment::fields()`). Из неё строятся мета-поля, форма в админке, импорт и ответ API.
- API проверяет параметры по схеме WordPress REST: неверное значение даёт ответ 400, до базы данных оно не доходит.
- Безопасность: nonce и проверка прав в админке, экранирование всего вывода, защита от формул в CSV, honeypot и ограничение 5 заявок за 10 минут с одного IP.
- Диапазоны для подсказок в фильтре кэшируются и сбрасываются при изменении квартир.

## Запуск локально

Нужен только Node.js: PHP и MySQL не требуются, всё работает через WordPress Playground.

```bash
npx @wp-playground/cli@latest server --port=9411 \
  --mount=./plugin/zhk-catalog:/wordpress/wp-content/plugins/zhk-catalog \
  --mount=./theme/zhk-theme:/wordpress/wp-content/themes/zhk-theme \
  --blueprint=./blueprint.json
```

Сайт: http://127.0.0.1:9411. Вход в админку выполняется автоматически.

## На реальном проекте

- Карта: заменить подложку на Яндекс Карты (нужен API-ключ).
- CRM: подключиться к действию `zhk_lead_created( $lead_id, $data )`.
- Если квартир больше нескольких тысяч, перенести данные в отдельную таблицу с индексами.
